## Features

- A React single page Admin Dashboard project about event booking. 
- The project includes some basic informations about an event booking. 
- The Dashboard page includes 5 components which are: Sidebar, Header, Dashboard event status, Events and Reports.
- The sidebar menus links to the page sections (dashboard, events and reports).
- It is build with mobile first mindset.
- Project in development and not yet a full functional one.

## Built with

- Reactjs-vite (react-router-dom, react-icons)
- Tailwind CSS
- CSS3
- HTML5 markup
